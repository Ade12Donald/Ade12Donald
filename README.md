## 🚀 Things I've built (and still working on)

### 🤝 SkillSwap *(in progress)*
A platform where people teach each other skills through mutual exchange.
- Express + MongoDB backend with JWT auth (cookie-based, role-checked admin routes)
- Skill-based user discovery, mutual matching, and a full connections flow (request, accept/reject, lists)
- Up next: real-time messaging with Socket.IO, skill sessions, notifications, reviews

### ⚡ WATTSENSE
An occupancy-driven energy saver for a UNILAG engineering challenge.
- **ESP32** + PIR motion sensor + CT clamp current sensor + relay + OLED display
- Detects when a room is empty, counts down, then cuts the load automatically
- Shows live wattage and ACTIVE/CUTOFF state on the display
